# Magical Birthday Memory Experience

Struktur:
- index.html  -> HTML
- style.css   -> CSS
- script.js   -> JavaScript + Three.js
- assets/music/ -> tempat file musik MP3
- assets/images/ -> tempat foto lokal jika ingin mengganti URL gambar

Catatan:
- Three.js dan GSAP masih memakai CDN seperti pada file asli.
- Jalankan melalui web server lokal jika browser membatasi module/CDN saat dibuka langsung.
